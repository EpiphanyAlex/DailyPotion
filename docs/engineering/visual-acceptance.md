# 页面视觉验收

状态：验收契约；认证与导航已实现，酒柜的具体证据见 [Phase 5 验收](phase-5-acceptance.md)，后续业务页依阶段补齐。视觉规格的唯一权威是 [design.md](../../design.md)；本文只规定取证方式。

从 Phase 4 第一个真实 Auth 页面开始，每个页面 PR 在浏览器用实际页面记录：

| 视口/状态 | 验收点 |
|---|---|
| 桌面 ≥1024px | 顶部导航、内容宽度和双栏/网格与 design.md 对齐；Auth 为左右分屏；无侧边栏 |
| 中间 768–1023px | 桌面内容布局 + Bottom Tab，无遮挡或横向滚动 |
| 移动 <768px | 单列布局、底部导航与 sticky action 不重叠；Auth 单列表单 |
| 空状态 | 无库存/无筛选结果时有明确说明和下一步入口；使用 `paper-deep` 等 token |
| 加载状态 | 列表与详情使用对应内容形状的 `paper-deep` skeleton；无突兀跳动 |
| 错误状态 | 输入错误、读取错误和写入失败可见，重试路径明确；danger token 与焦点环合规 |

首个 Auth 页面至少验证桌面登录、移动登录/注册、无效输入、提交中、认证失败；空状态检查可在首个酒柜页落实。每个真实页面按其 feature PRD 补齐状态和 zh/en 文案，附桌面与移动截图或浏览器记录；自动 token 检查只防止值漂移，不能替代目视验收。Pencil 源 PR #7 尚未视觉审查，其合并不等于页面验收。
